Ian Repik's Artwork API

The server behind my React art gallery.

View Artwork

GET /api/artworks returns the artwork list.

Open Artwork API

Add Artwork

POST /api/artworks adds artwork to the list.

  • Title: 3–80 characters
  • Medium: 3–80 characters
  • Year: four-digit text from 1900–2100
  • Description: 10–1000 characters
  • Image: one of the six choices in the form

Successful requests return status 201. Invalid requests return status 400 with an error message.
